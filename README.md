## About

WarXFolio is a modern, open-source developer portfolio engineered for speed, maintainability, and effortless customization.

Whether you're a student, freelancer, or professional developer, WarXFolio provides a clean foundation for showcasing your work without unnecessary complexity.

---

## Highlights

- Responsive across all devices
- Clean and maintainable architecture
- Smooth animations
- Modern dark interface
- Optimized performance
- Highly customizable
- Production-ready
- Vercel compatible
- MIT Licensed

## Installation

```bash
git clone https://github.com/riyanshu524-hue/WarXFolio.git

cd WarXFolio

npm install

npm run dev
```

---

## Production Build

```bash
npm run build
```

Preview locally

```bash
npm run preview
```
